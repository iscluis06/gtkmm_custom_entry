#  GTKMM Custom Entry Widget

Simple custom entry widget that allows only inserting characters or numerics.

### Requirements

* gtkmm 4 (GTK binding for C++)
* pkgconfig (development only)

```shell
apt install pkgconf-bin pkgconf libgtkmm-4.0-0 libgtkmm-4.0-dev
```
